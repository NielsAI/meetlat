# Calques: English phrasing carried into Dutch word for word. One phrase per line,
# lowercase, matched as a whole-word substring.
#
# The bar for adding a line is high on purpose (ADR-0002). A phrase belongs here
# only if a Dutch writer would not produce it unprompted in ANY register. Phrases
# that are merely common in machine output but defensible in Dutch stay out, and
# some near-misses are listed at the bottom with the reason, so nobody re-proposes
# them.

laten we duiken in

ik hoop dat dit helpt

voel je vrij om
voelt u zich vrij om
dat gezegd hebbende
ik waardeer je vraag
ik waardeer uw vraag
